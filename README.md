# SOW de NahuCS
Esto es un sistema operativo dentro del navegador, con escritorio, ventanas y barra de tareas. 
El proyecto aún está en desarrollo.
## Funcionalidades
- Mover una ventana.
- Minimizar, maximizar y cerrar una ventana.
- Icono en el escritorio que con doble click se vuelve a abrir la ventana.
- Barra de tareas con reloj y botón de inicio cuyo menú muestra tres botones que aún no hacen nada.
## Tecnologías
Las tecnologías que uso para este proyecto son HTML, CSS y JS sin librerías. 
## Cómo ejecutarlo
Para ejecutarlo basta con abrir el archivo index.html.
